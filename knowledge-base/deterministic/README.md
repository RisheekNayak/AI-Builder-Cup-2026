# ShipSure Knowledge Base

This repository contains the curated knowledge base powering ShipSure's RAG system.

## Official Regulatory Sources

### DGFT SCOMET Appendix 3
- **Source:** DGFT Portal (dgft.gov.in)
- **Notification:** Notification No. 31/2025-26 (dated September 23, 2025)
- **Download Instructions:** Navigate to dgft.gov.in -> Services/Regulatory -> SCOMET. Look for the latest updated SCOMET List and download the PDF.

### ITC(HS) Classification Schedule (Chapters 84-90)
- **Source:** DGFT Portal
- **Download Instructions:** The schedule is available as an interactive searchable portal on the DGFT website. Export/print the results for specific chapters after searching.

### India-UAE CEPA Rules of Origin
- **Source:** Department of Commerce, Government of India (commerce.gov.in)
- **Download Instructions:** Rules of Origin (Chapter 3) and Operational Certification Procedures (OCPs) are found within the signed CEPA document text on the commerce portal.

### ICEGATE Shipping Bill format/message specification
- **Source:** ICEGATE Portal
- **Version:** SB Message Format Ver - 3.5
- **Download Instructions:** Navigate to icegate.gov.in -> Message Filing Guidelines -> EDI Message Formats.

### DGFT Foreign Trade Policy (FTP 2023) Handbook of Procedures
- **Source:** DGFT Portal
- **Download Instructions:** Navigate to dgft.gov.in -> Policy -> Foreign Trade Policy 2023 -> Handbook of Procedures.

## Note on Manual Downloads
Direct automated downloads (via curl/wget) for these PDFs are often blocked by government websites to prevent scraping. Please follow the manual download instructions above to retrieve the latest copies into `knowledge-base/raw/`.
